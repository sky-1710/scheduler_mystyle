## 1. 시작하기

| 하고 싶은 것 | 방법 |
|---|---|
| 앱 열기 | 시작 메뉴(또는 바탕화면)의 **내 스케줄러** |
| 창 닫기 | 창의 ✕ → **트레이로 숨어서 계속 실행**됩니다 (알림·뽀모도로 그대로 동작) |
| 다시 열기 | 작업 표시줄 트레이 아이콘 클릭, 또는 앱을 한 번 더 실행 (새로 뜨지 않고 기존 창이 앞으로 나옴) |
| 완전히 끄기 | 트레이 아이콘 우클릭 → **종료** (알림도 멈춤) |
| PC 켤 때 자동 실행 | `.venv\Scripts\python run.pyw --autostart on` (끄기: `off`) |

- 저장 버튼은 없습니다. 모든 변경이 **`data/schedule_data.json`에 바로 자동 저장**됩니다.
- 처음 설치하는 방법은 [docs/설치-가이드.md](docs/설치-가이드.md)를 보세요.

## 2. 화면 구성

### 하단 탭 (6개)

| 키 | 탭 | 용도 |
|---|---|---|
| `1` | 📅 월간 | 달력, 기간 일정 막대, 날짜별 할일·습관 % |
| `2` | 📆 주간 | 요일별 습관 체크 카드 + 시간표 |
| `3` | ⏱️ 일간 | 종이 플래너식 하루 페이지 — 할일, 습관, **10분 타임블록**, 메모, 하루 평가 |
| `4` | 🔥 습관 | 한 달 습관 체크 그리드 |
| `5` | ✅ 할일 | 기한 초과 / 오늘 / 예정 / 완료 / 보관 목록 |
| `6` | 📊 통계 | 주간·월간·연간 기록 시간, 성공률, 히트맵 |

### 상단 버튼

| 버튼 | 하는 일 |
|---|---|
| 📌 | 왼쪽 D-day 패널 열기/닫기 |
| ⏺ 기록 칩 | 타이머가 돌 때만 보임. 경과 시간 표시, **누르면 기록 중지** |
| 💾 | 저장 상태 · 다운로드 · 가져오기 · 시작 화면 켜기 · Google 캘린더 |
| 🧩 | **위젯 모드** (항상 위에 떠 있는 미니 창) 열기/닫기 |
| 🔍 | 통합 검색 (할일·일정·습관·메모·목표·반성) |
| 🌙 / ☀️ | 다크 모드 / 라이트 모드 |
| ＋ | 일정·할일 추가 |
| ‹ › 오늘 | 현재 탭 기준으로 이전/다음/오늘 이동 |

## 3. 모드 한눈에 보기

| 모드 | 켜는 곳 | 한 줄 설명 |
|---|---|---|
| **시간 기록 (타이머)** | 할일·습관 줄 클릭 | 스톱워치가 돌면서 1분 단위로 시간을 쌓고 타임블록을 자동으로 칠함 |
| **색칠 모드** | 일간 탭 → 할일 선택 후 TIME PLAN 클릭·드래그 | 지난 시간을 손으로 칠해서 기록 |
| **지우개 모드** | 일간 탭 → 🧹 지우개 | 칠한 시간 지우기 |
| **위젯 모드** | 상단 🧩 | 다른 창 위에 항상 떠 있는 미니 카드 (끌어서 옮기기·접기) |
| **집중 화면** | 위젯에서 기록이 시작되면 자동 | 위젯이 스톱워치 + 할 일 이름 + 남은 뽀모도로 시간(링)만 보여줌 |
| **뽀모도로 모드** | 위젯 타이머 방식 「뽀모도로」 | 할 일을 누르면 집중 타이머가 시작되고, 끝나면 알림 → 휴식 |
| **집중 모드** | 위젯 타이머 방식 「집중 모드」 | 뽀모도로를 **같은 할 일로 버튼 없이 계속 반복** (중지할 때까지) |
| **알림: 일반 / 알람** | 일정 만들 때 「알림」 옆 선택 | 잠깐 뜨는 알림 / 직접 닫을 때까지 남는 알림 |
| **다크 모드** | 상단 🌙 | 어두운 테마 |
| **시작 화면** | 하루 첫 실행 때 자동 | 목표를 떠올리는 전체 화면 (💾 메뉴에서 켜고 끔) |
| **Google 캘린더 연동** | 💾 메뉴 | 일정을 구글 캘린더로 보내서 휴대폰에서 알림 받기 |

## 4. 시간 기록 (타이머)

"지금 이걸 하고 있다"를 누르면 그때부터 시간이 자동으로 쌓이는 기능입니다.

**시작**
- 위젯의 할 일·습관 **줄을 클릭**, 또는
- 일간 탭의 TO DO LIST / HABIT TRACKER **줄을 클릭**

**동작**
- 상단에 ⏺ 기록 칩과 초 단위 타이머 바가 나타납니다.
- 시간은 **1분 단위로 정확하게** 적립되고, TIME PLAN의 현재 칸이 자동으로 칠해집니다.
- 칸 중간(예: 10:07)에 시작해도 그 분부터 정확히 칠해집니다.

**멈추기 · 바꾸기**
- 같은 줄을 **다시 클릭** = 중지
- **다른 줄 클릭** = 그 할 일로 전환
- 상단 ⏺ 기록 칩 클릭, 타이머 바의 ■, 위젯 집중 화면의 「■ 중지」도 모두 중지

## 5. 타임블록 색칠 · 지우개

일간 탭 TIME PLAN은 **24시간 × 10분 칸** 그리드입니다. 이미 지난 시간을 손으로 기록할 때 씁니다.

1. TO DO LIST나 HABIT TRACKER에서 칠할 **할 일을 선택**합니다.
2. TIME PLAN에서 **클릭 또는 드래그**합니다.

| 조작 | 결과 |
|---|---|
| 칸 안을 클릭 | 누른 위치만큼 **1분 단위로** 채움 (칸의 30% 지점 = 3분) |
| 드래그 | 지나간 칸은 꽉, 마지막 칸은 놓은 위치만큼 채움 |
| 다른 할 일로 같은 칸 칠하기 | 겹친 분만 바뀌고 나머지는 남음 (한 칸을 두 작업이 나눠 쓸 수 있음) |
| 자기 색 위를 다시 클릭 | 그 작업만 지워짐 |
| 🧹 지우개로 클릭 | 누른 위치의 작업만 지움, 빈 곳을 누르면 칸 전체 지움 |

WAKE / SLEEP 시간을 적으면 그리드에 ☀️/🌙 세로선이 그어지고 수면 시간이 자동 계산됩니다.

## 6. 위젯 모드

상단 **🧩** 를 누르면 **다른 프로그램 위에 항상 떠 있는 작은 카드**가 열립니다. 공부·작업하면서 띄워두는 용도입니다.
데스크톱 앱에서는 제목 표시줄 없이 **바탕화면 위에 둥근 카드로** 떠 있고, 작업 표시줄에는 나타나지 않습니다.

```
┌─────────────────────────────────┐
│ 10월 28일 수요일            —  ✕ │  ← 끌어서 옮기기 · 접기 · 닫기
│ 21:36             할 일 1/3 ▬▬  │
│                   습관  0/2 ▬▬  │
│ [ ● 기록 │ 뽀모도로 │ 집중 모드 ] │  ← 타이머 방식
│    할 일을 누르면 … 시작됩니다     │
├─────────────────────────────────┤
│ 오늘 할일                   1/3 │
│ [+ 할일 추가 후 Enter] [불러오기] │
│ ○ 수학 문제집 3단원              │
│ ✓ 영어 단어 50개 외우기           │
│ 습관                        0/2 │
│ ○ 물 2L 마시기                  │
└─────────────────────────────────┘
```

**위젯에 있는 것**
- 날짜 · 시계 · 오늘 할 일/습관 진행 막대
- **타이머 방식**: 「기록」 · 「뽀모도로」 · 「집중 모드」 중 하나를 고릅니다 ([7번](#7-뽀모도로-모드), [8번](#8-집중-모드-연속-뽀모도로))
- 「뽀모도로」·「집중 모드」일 때만: 집중/휴식 시간, 알림 소리 장치
- 오늘 할일 목록, 빠른 추가 입력창, **불러오기**, 습관 목록

**조작**

| 조작 | 결과 |
|---|---|
| 줄 클릭 (마우스를 올리면 ▶ 표시) | 그 할 일의 **시간 기록 시작** (뽀모도로면 집중 시작) |
| 동그라미 클릭 | 완료 체크 |
| ✕ 두 번 클릭 (마우스를 올리면 보임) | 삭제 (한 번 누르면 「확인」으로 바뀜). 불러온 할일은 오늘 목록에서만 빠짐 |
| 입력창에 제목 + Enter | 오늘 할일 바로 추가 (같은 제목이 있으면 색·카테고리 이어받음) |
| 「불러오기」 | 다른 날짜·월간·주간 할일을 오늘로 가져오기 (아래) |

**불러오기**: 다른 날짜의 미완료 할일이나 월간·주간 할일을 **오늘 목록으로 가져옵니다.** 본 창 일간 탭의 「가져오기」와 같은 기능입니다.
- 「불러오기」를 누르면 목록이 후보로 바뀝니다. 후보를 누르면 체크되며 오늘에 추가되고, 다시 누르면 빠집니다.
- 입력창에 글자를 치면 후보가 **검색**됩니다. 찾는 게 없으면 그대로 Enter → 새 할일로 추가됩니다.
- 「완료」를 누르면 오늘 목록으로 돌아옵니다.

**창 다루기** (데스크톱 앱)

| 조작 | 결과 |
|---|---|
| 제목 줄·시계 등 빈 곳을 끌기 | 위젯 옮기기 — 다음에 열 때도 그 자리에서 열림 |
| — (접기) | 시계 한 줄짜리 **작은 알약**으로 접힘. 기록 중이면 할 일 이름·시간·■ 중지가 보이고, 뽀모도로 중이면 아래에 **남은 시간 바**가 붙음 |
| ⤢ (펼치기) | 원래 크기로 |
| ✕ | 위젯 닫기 (🧩 로 다시 열기) |

위젯 높이는 내용에 맞춰 저절로 줄었다 늘어납니다. 할 일이 많으면 목록 부분만 스크롤됩니다.

**집중 화면**: 기록이 시작되면 위젯이 할 일 이름, 스톱워치, 오늘 누적 시간, 「■ 중지」만 보여주는 화면으로 바뀝니다. 뽀모도로 중이면 남은 시간이 **원형 진행 링**으로 보입니다. 기록을 멈추면 원래 위젯으로 돌아옵니다.

> 위젯을 닫아도 타이머와 뽀모도로는 본 창에서 계속 돕니다.

## 7. 뽀모도로 모드

**집중 → 휴식**을 정해진 시간으로 나눠서 하는 방식입니다. 위젯의 타이머 방식에서 **「뽀모도로」** 를 고르면 바로 아래에 설정이 나타납니다.

```
[ ● 기록 │  뽀모도로  │ 집중 모드 ]
 집중  − 25분 +      휴식  − 5분 +
 소리  [기본 장치 ▾]            ▶
      할 일을 누르면 집중이 시작됩니다
```

### 7-1. 설정

| 항목 | 범위 | 설명 |
|---|---|---|
| 집중 | 5 ~ 120분 (5분 단위) | `−` / `+` 로 조절 |
| 휴식 | 0 ~ 60분 (5분 단위) | 0분이면 「없음」 |
| 소리 | 출력 장치 선택 | [9. 알림 소리 출력 장치](#9-알림-소리-출력-장치) |

설정은 저장되어 다음에도 그대로입니다. 세션이 도는 동안에는 설정 칸 대신 남은 시간과 「중지」가 보이므로, 바꾸려면 먼저 중지하세요.

### 7-2. 시작하기

1. 위젯의 타이머 방식에서 **「뽀모도로」를 고릅니다.** 고르기만 해서는 아무것도 시작되지 않습니다.
2. **할 일을 누르면** 그 할 일로 집중이 시작됩니다. 「시작」 버튼은 따로 없습니다.
   - 위젯의 줄을 눌러도 되고, 본 창 일간 탭의 TO DO LIST 줄을 눌러도 됩니다.
3. 집중하는 동안 그 할 일의 시간이 기록됩니다.

### 7-3. 기본 흐름 (집중 모드 꺼짐)

| 구간이 끝나면 | 일어나는 일 |
|---|---|
| **집중** 끝 | 알림 한 번 → 할 일 기록이 멈추고 위젯에 **「집중 완료」** 와 버튼이 나타남 |
| 「휴식 시작」 클릭 | 휴식 카운트다운 시작 |
| **휴식** 끝 | 알림 한 번 → **같은 할 일로 집중이 자동으로 다시 시작** |

- 집중이 끝난 뒤에는 **버튼을 누를 때까지 기다립니다** (저절로 휴식으로 넘어가지 않음).
- 휴식 없이 바로 다음 집중을 하려면 그 할 일을 **다시 누르면** 됩니다.
- 휴식을 **0분(없음)** 으로 두면 집중 한 번으로 끝납니다.
- 휴식 동안에는 기록을 멈춥니다. **쉬는 시간이 공부 시간으로 잡히지 않게** 하기 위해서입니다.

**버튼 없이 계속 이어가고 싶다면 → [8. 집중 모드](#8-집중-모드-연속-뽀모도로)**

### 7-4. 중지하기

| 언제 | 방법 |
|---|---|
| 집중 중 | 위젯 집중 화면의 「■ 중지」, 할 일 다시 클릭, 상단 ⏺ 기록 칩 클릭 |
| 휴식 중 | 위젯의 「중지」 |
| 「집중 완료」 대기 중 | 위젯의 「종료」 |

뽀모도로를 아예 안 쓰려면 「기록」을 고릅니다. 그러면 할 일을 눌러도 시간 기록만 됩니다.

### 7-5. 알아두면 좋은 점

- 카운트다운은 본 창에서 돌기 때문에 **위젯을 닫거나 창을 트레이로 숨겨도** 세션이 계속되고, 끝나면 알림이 옵니다.
- 알림은 **직접 닫을 때까지 화면에 남는 Windows 알림 + 알림음**입니다. 각 구간이 끝날 때 **한 번씩만** 울립니다.

## 8. 집중 모드 (연속 뽀모도로)

**할 일을 한 번만 누르면, 중지할 때까지 같은 할 일로 뽀모도로가 계속 이어지는 모드**입니다.
중간에 버튼을 누르거나 할 일을 다시 고를 필요가 없습니다.

### 켜기

위젯의 타이머 방식에서 **「집중 모드」** 를 고릅니다.
- 집중·휴식 시간과 소리는 「뽀모도로」와 **같은 설정**을 씁니다.
- 「뽀모도로」를 고르면 버튼 대기 방식으로, 「기록」을 고르면 뽀모도로 없이 시간 기록만 됩니다.
- 고르면 위젯에 「할 일을 누르면 시작 · 중지할 때까지 계속 이어집니다」라고 나옵니다.

### 흐름

```
할 일 클릭
  ↓
🍅 집중 25분  (시간 기록 중)
  ↓ 알림 「집중 완료 — 5분 휴식을 시작합니다」
☕ 휴식 5분   (기록 멈춤, 자동 시작)
  ↓ 알림 「휴식 끝 — 다시 집중을 시작합니다」
🍅 집중 25분  (같은 할 일로 자동 시작)
  ↓
☕ 휴식 5분
  ↓
  …  「중지」를 누를 때까지 반복
```

| | 집중 모드 꺼짐 | **집중 모드 켜짐** |
|---|---|---|
| 집중이 끝나면 | 「휴식 시작」 버튼을 기다림 | **바로 휴식 시작** |
| 휴식이 끝나면 | 같은 할 일로 집중 재개 | 같은 할 일로 집중 재개 |
| 휴식 0분일 때 | 집중 한 번으로 끝 | **집중만 연달아 계속** (기록도 끊기지 않음) |
| 끝내는 법 | 「종료」·「중지」 | 「중지」 |

### 진행 중 표시

- 집중 중(위젯 집중 화면): 링 안에 남은 시간과 `🍅 집중 25분` + 반복 아이콘(⟳)
- 휴식 중(위젯): `휴식 중 · 끝나면 집중 재개` 아래에 `⟳ 집중 모드 · 중지할 때까지 계속`

### 중지하기

[7-4. 중지하기](#7-4-중지하기)와 같습니다. 집중 중이면 「■ 중지」·할 일 다시 클릭·⏺ 기록 칩, 휴식 중이면 위젯의 「중지」.

> **자리를 오래 비울 때는 꼭 중지하세요.** 집중 모드는 휴식이 끝나면 스스로 다음 집중을 시작하므로,
> 켜둔 채 자리를 뜨면 그동안도 그 할 일의 시간으로 기록됩니다.

## 9. 알림 소리 출력 장치

뽀모도로 알림음이 **어느 장치로 나올지** 직접 고릅니다. (데스크톱 앱 전용)

1. 위젯에서 「뽀모도로」나 「집중 모드」를 고르면 나오는 **「소리」** 목록에서 장치를 고릅니다 (스피커, 이어폰, 헤드셋 등).
2. **▶** 를 누르면 고른 장치로 미리 들을 수 있습니다.

| 상황 | 동작 |
|---|---|
| 아무것도 안 고름 | **기본 장치** (Windows 기본 출력)로 울림 |
| 고른 장치가 빠져 있음 | 목록에 「(연결 안 됨)」 표시, **그동안은 기본 장치로** 울림 |
| 다시 연결 | 자동으로 고른 장치로 돌아감 |
| 이어폰·블루투스를 꽂거나 뺌 | 목록이 바로 갱신됨 |

알림음 파일은 `assets/alarm.wav` 이며 처음 실행할 때 자동으로 만들어집니다 (지워도 다시 생김).

## 10. 일정 · 할일 만들기

상단 **＋** (또는 `N` 키)로 엽니다.

| 항목 | 설명 |
|---|---|
| 유형 | **일정**(날짜·시간 지정) ↔ **할 일**(체크리스트) |
| 기간 | 종료일을 넣으면 기간 일정 (월간 달력에 연속 막대, D-day는 종료일 기준) |
| 할일 범위 | 특정 날짜 / **주간 할일**(그 주 전체) / **월간 할일**(그 달 전체) |
| 반복 | 매일 / **N일마다** / 매주 / 매월 / 매년 + 반복 종료일. 반복 할일은 **날짜별로 따로 완료 체크** |
| 알림 | 알림 없음 / 5분 · 10분 · 30분 · 1시간 · 하루 전 + 방식(일반/알람) |
| 카테고리 | 드롭다운 선택, ⚙ 관리에서 만들기. 제목이 기존 할일과 같으면 자동 지정 |
| 기타 | 색상, 중요도, 정확도(%), 메모 |

- 기간과 반복은 함께 쓸 수 없습니다.
- 주간·월간 할일은 달력 칸에 나타나지 않고, 월간·주간 탭 왼쪽 패널에서 관리합니다. 일간 탭의 📥 가져오기로 특정 날에 끌어와 작업할 수 있습니다. 지난 기간 미완료는 「↪ 이월하기」로 넘깁니다.

## 11. 일정 알림 (일반 / 알람)

일정에 **시작 시간 + 알림**을 설정하면 그 시각에 Windows 알림이 뜹니다.

| 방식 | 동작 |
|---|---|
| **일반** | 잠깐 떴다가 알림 센터로 들어감 |
| **알람 (직접 닫기)** | 직접 닫을 때까지 화면에 남고, 5 · 10 · 30분 뒤 「다시 알림」 선택 가능 |

- 마지막으로 고른 방식이 다음 일정의 기본값이 됩니다.
- 시간이 없는 할일, 주간·월간 할일에는 알림이 걸리지 않습니다.
- 창을 닫아도(트레이) 알림은 울립니다. **트레이에서 「종료」하면 알림도 멈춥니다.**
- PC가 꺼져 있을 때도 받으려면 → [14. Google 캘린더 연동](#14-google-캘린더-연동)

## 12. 탭별 기능

### 📅 월간
- 날짜 칸에 일정 칩, 날짜 옆에 **습관 %(주황) · 할일 %(보라)**
- 날짜 클릭 → 그날 일정 목록, 타임블록 보기, 주간 보기, 일정 추가
- 왼쪽 패널 아래 「🗓 N월 할일」 = 월간 할일

### 📆 주간
- 위: 요일별 습관 체크 카드 (달성률, 진행 막대)
- 아래: 시간표 — 빈 칸 클릭 = 그 시간에 일정 추가

### ⏱️ 일간 (DAILY PLANNER)
- **DATE / GOAL / DONE**: 날짜, 오늘 목표, 완료율 + 최근 7일 그래프
- **WAKE / SLEEP**: 기상·취침 시각 → 수면 시간 자동 계산
- **TO DO LIST**: ＋ 추가, 📥 가져오기, 🧹 지우개. 동그라미 = 완료, 줄 클릭 = 기록 시작 + 색칠 대상, ✎ = 수정
- **HABIT TRACKER**: 습관도 똑같이 체크·기록
- **TIME PLAN**: 10분 타임블록 ([5번](#5-타임블록-색칠--지우개))
- **MEMO**: 모눈 메모장, 🖼️ 사진 추가 또는 Ctrl+V 붙여넣기
- **TODAY'S REVIEW**: ⭐ 10점 별점 + 반성 기록

### 🔥 습관
- 세로 = 습관, 가로 = 날짜인 한 달 그리드. 칸 클릭 = 체크
- 이름 옆에 달성률, 이름 클릭 = 수정/삭제, ＋ 습관 추가

### ✅ 할일
- 기한 초과 / 오늘 / 예정 / 날짜 없음 / 완료(접힘) / 보관됨(접힘)
- 우선순위 순 정렬, 완료 후 14일 지난 할일은 자동 보관

### 📊 통계
- **[주간 | 월간 | 연간]** 전환, ‹ › 로 기간 이동
- 요약 카드(지난 기간 대비 ▲▼), 기록 시간·별점 추이, 카테고리별 시간·성공률, 습관 달성률
- 연간: 🌱 잔디 히트맵
- **⬇ CSV**: 현재 기간의 시간 기록을 엑셀용으로 내보내기

### 📁 카테고리
- 일정/습관 창의 **⚙ 관리**에서 이름·색·**상위 카테고리**(`공부 > 수학`)·주간 목표 시간 설정
- 통계는 하위 → 상위로 합산

- 💾 메뉴 → **Google 캘린더 연결** → 브라우저에서 로그인
- 연결 후에는 일정을 고치면 **4초 뒤 자동 반영**, 「지금 동기화」로 즉시 실행

- 「재로그인 필요」가 뜨면 눌러서 다시 로그인 (테스트 상태에서는 7일마다 만료)

처음 한 번 인증 파일 설정이 필요합니다 → [docs/구글-캘린더-연동.md](docs/구글-캘린더-연동.md)

## 17. 자주 묻는 질문

**Q. 뽀모도로가 한 번 끝나면 할 일을 다시 골라야 해요.**
→ 위젯에서 **「집중 모드」** 를 켜세요. 중지할 때까지 같은 할 일로 계속 이어집니다. ([8번](#8-집중-모드-연속-뽀모도로))

**Q. 「뽀모도로」를 골랐는데 타이머가 안 돌아요.**
→ 고르기만 해서는 시작되지 않습니다. **할 일을 눌러야** 집중이 시작됩니다.

**Q. 휴식 시간까지 공부 시간으로 잡히나요?**
→ 아니요. 휴식 동안에는 기록을 멈춥니다. (집중 모드에서 휴식을 0분으로 두면 쉬는 구간이 없으므로 계속 기록됩니다.)

**Q. 알림 소리가 이어폰으로만 나와요 / 스피커로만 나와요.**
→ 위젯에서 「뽀모도로」를 고른 뒤 **「소리」** 에서 원하는 장치를 고르세요. ([9번](#9-알림-소리-출력-장치))

**Q. 창을 닫았더니 알림이 안 와요.**
→ ✕로 닫으면 트레이에 남아 계속 동작합니다. 트레이에서 **「종료」** 를 눌렀다면 다시 실행하세요.

**Q. 위젯이 안 열려요.**
→ 상단 🧩 를 다시 눌러보세요. 이미 열려 있으면 🧩 가 진하게 표시되고, 누르면 닫힙니다.

**Q. 위젯이 화면을 가려요.**
→ 제목 줄을 끌어서 옮기거나, **—** 를 눌러 작은 알약으로 접어두세요. 옮긴 자리는 기억됩니다.

**Q. 데이터를 다른 PC·폰으로 옮기고 싶어요.**
→ 💾 → ⬇ 다운로드 → 옮긴 기기에서 ⬆ 가져오기. 자세한 방법은 [docs/설치-가이드.md](docs/설치-가이드.md).
