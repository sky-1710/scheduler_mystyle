# 내 스케줄러 (My Scheduler)

종이 다이어리 감성의 **개인 일정·할일·습관·시간 관리 플래너**입니다.
단 하나의 `index.html` 파일로 동작하며, 설치나 서버 없이 브라우저만 있으면 Windows와 Android에서 모두 사용할 수 있습니다.

![구성](https://img.shields.io/badge/구성-단일%20HTML-blue) ![의존성](https://img.shields.io/badge/외부%20의존성-없음-green)

## 주요 기능

| 기능 | 설명 |
|---|---|
| 📅 **월간 / 주간 / 일간 뷰** | 달력, 주간 시간표, 종이 플래너 스타일 일간 페이지 |
| ⏱️ **10분 타임블록 트래커** | 할일·습관을 선택해 색칠하거나, ▶ 버튼으로 실시간 자동 기록 |
| ✅ **할일 관리** | 우선순위·반복(N일마다 포함)·알림·정확도·메모, 반복 할일은 날짜별 완료 |
| 🗓 **월간/주간 할일** | 달·주 단위 목표를 패널에서 관리, 미완료 자동 이월 버튼 |
| 📆 **기간 일정** | 시작일~종료일 지정 시 달력에 연속 막대로 표시, D-day는 종료일 기준 |
| ⭐ **하루 평가** | 10점 별점 + 반성 기록, 통계에서 별점·기록 시간 추이 라인 그래프 |
| 🧩 **위젯 모드** | 항상 위에 떠 있는 미니 창 — 클릭 한 번으로 타이머 시작/전환 (열품타 스타일) |
| 🔥 **해빗 트래커** | 일간 체크리스트 + 주간 카드 + 월간 그리드, 스트릭 표시 |
| 📁 **중첩 카테고리** | `공부 > 수학` 식 분류, 주간 목표 시간 설정 |
| 📊 **통계** | 주간/월간/연간 토글 — 증감 비교, 스택 그래프, 잔디 히트맵, 성공률 |
| 📝 **날짜별 GOAL / MEMO / 사진** | 모눈 메모장에 사진 첨부(붙여넣기 지원) |
| 💾 **자동 백업** | 폴더 연결 시 JSON 자동 저장 + 주간 스냅샷, 어디서나 다운로드/가져오기 |

## 빠른 시작

1. `index.html`을 Chrome/Edge에서 엽니다.
2. 상단의 **📁 data 폴더 연결**을 눌러 `data` 폴더를 선택합니다 → 이후 모든 변경이 자동 저장됩니다.
3. `+` 버튼으로 첫 할일을 만들고, **일간(⏱️) 탭**에서 색칠해보세요.
