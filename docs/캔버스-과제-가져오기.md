# Canvas 과제 가져오기

학교 Canvas(LMS)에 올라온 **마감일 있는 과제**를 이 앱의 할일로 자동으로 넣어주는 기능입니다.
데스크톱 앱(`run.pyw`)에서만 동작합니다. 브라우저로 `index.html`을 직접 연 경우에는 메뉴가 보이지 않습니다.

## 어떻게 가져오나 — 그리고 왜 학교에서 문제가 되지 않나

Canvas는 모든 학생에게 **개인 캘린더 피드 주소**(`…/feeds/calendars/user_….ics`)를 줍니다.
Google 캘린더·Outlook·휴대폰 캘린더에 "구독"하라고 Canvas가 직접 제공하는 공식 기능입니다.
이 앱은 **그 주소 하나를 읽기만** 합니다.

| | 이 앱이 하는 것 | 하지 않는 것 |
|---|---|---|
| 로그인 | 없음 (피드 주소만 사용) | 학번·비밀번호 입력, SSO 자동 로그인 |
| 인증 정보 | 없음 | 브라우저 쿠키·세션 복사, API 토큰 |
| 요청 | 피드 1개를 HTTPS GET 1번 | 강의 페이지 긁어오기(스크래핑), API 여러 개 호출 |
| 빈도 | 자동은 **6시간에 최대 1번**, 버튼은 1분에 1번 | 수시로 폴링 |
| 출발지 | 내 PC, 평소 Canvas를 여는 것과 같은 IP | 다른 서버·VPN·프록시 경유 |

- 학교 네트워크에서 보이는 것은 **Canvas 서버로 가는 HTTPS 연결**뿐이고, 브라우저로 Canvas를 여는 것과 구별되지 않습니다.
- Canvas 서버 입장에서는 캘린더 앱이 구독 피드를 읽어가는 것과 같은 요청입니다.
  Google 캘린더에 구독하면 Google 서버가 같은 주소를 몇 시간마다 읽어가는데, 이 앱은 그보다 드물게, 내 PC에서 읽습니다.
- 앱은 자신을 `MyScheduler/1.0 (personal Canvas calendar feed reader)`로 밝힙니다. 브라우저인 척하지 않습니다.
- 주소가 거부되면(만료·오타) 자동 재시도를 **멈춥니다**. 실패한 요청이 쌓이지 않도록 하기 위해서입니다.

> 개발자 도구(F12 → Network)에서 보이는 `calendar_events?type=assignment` 같은 요청을
> 쿠키째 복사해 다시 보내는 방식은 쓰지 않습니다. 로그인 세션을 파일에 들고 다니게 되고,
> 세션이 다른 프로그램에서 재사용되는 패턴은 보안 시스템이 이상 징후로 볼 수 있기 때문입니다.

## 설정 (1분)

### 1. Canvas에서 피드 주소 복사

1. 브라우저로 학교 Canvas 접속 → 왼쪽 메뉴 **캘린더(Calendar)**
2. 오른쪽 아래(또는 오른쪽 사이드바 맨 아래) **캘린더 피드(Calendar Feed)** 클릭
3. 나오는 주소를 복사 — `https://학교주소/feeds/calendars/user_긴문자열.ics` 형태

> 이 주소는 **비밀번호처럼 다뤄주세요.** 주소를 아는 사람은 누구나 내 Canvas 일정을 볼 수 있습니다 (읽기만 가능).
> 앱은 이 주소를 `data/.canvas.json`에만 저장하며, `data/`는 `.gitignore`에 등록돼 있어 커밋되지 않습니다.

### 2. 앱에 붙여넣기

1. 상단 💾 버튼 → **Canvas 과제 가져오기**
2. 입력칸에 주소 붙여넣기 → **연결** (또는 Enter)
3. 바로 한 번 가져오고, 이후로는 6시간마다 알아서 확인합니다

## 무엇이 들어오나

| Canvas | 이 앱 |
|---|---|
| 마감일 있는 과제·퀴즈·채점 토론 | 할일 (마감 날짜·시각) |
| 제목 `과제명 [과목코드]` | 그대로 할일 제목 |
| 과목 `이름_ABC1234_01(교수)` | **「학교」 아래 과목 카테고리**(예: `학교 > Operating Systems`)를 자동으로 만들어 연결. 할일 색 = 카테고리 색 |
| 과목 코드 없는 항목 (학교 공통 교육 퀴즈 등) | 「학교」 카테고리에 바로 |
| `자정까지` (다음날 00:00 마감) | **전날 23:59** 할일로 — 실제로 끝내야 하는 날에 보이도록 |
| 강의·면담 같은 일반 일정 | 가져오지 않음 |
| 마감일 없는 과제 | 피드에 없어서 가져올 수 없음 |

### 규칙

- **처음 연결할 때는 마감이 오늘 이후인 과제만** 들어옵니다. 지난 과제로 목록이 덮이지 않습니다.
- **지운 할일은 다시 생기지 않습니다.** 한 번 보여준 과제는 기억해 둡니다 (연결을 해제했다 다시 해도 유지).
- 교수님이 **마감을 미루거나 제목을 바꾸면 따라갑니다.** (토스트: "마감 변경 N건")
- 내가 직접 바꾼 제목·날짜·색·완료 체크는 Canvas 쪽이 바뀌지 않는 한 건드리지 않습니다.
- 할일을 수정 창에서 고쳐 저장해도 Canvas에서 온 할일이라는 표시는 유지됩니다.

### 카테고리

- 과제는 **「학교」 아래**로만 갑니다. 「공부」는 순수하게 스스로 공부한 시간을 재는 곳이라 과제를 넣지 않습니다.
  그래서 `공부 > 운영체제`와 `학교 > Operating Systems`는 따로 있는 게 정상입니다.
- 과목 카테고리의 **이름·색·위치는 마음대로 바꿔도 됩니다.** 연결은 카테고리에 저장된 과목 정보로 하기 때문에,
  `Operating Systems` → `운영체제 과제`로 바꿔도 그 과목의 새 과제는 계속 거기로 들어오고 바뀐 색을 따릅니다.
- 할일 하나를 직접 다른 카테고리로 옮기면 그대로 둡니다.
- 「학교」 카테고리가 없으면 새로 만듭니다. 이름을 바꿔도 같은 카테고리를 계속 씁니다.
- 과목 카테고리를 지우면 그 할일들은 「학교」로 올라가고, 그 과목의 새 과제가 오면 카테고리가 다시 생깁니다.
- Google 캘린더 연동을 켜 두었다면 가져온 과제도 다른 할일처럼 `☑ 제목`으로 넘어갑니다.

## 한계

- **제출 여부는 알 수 없습니다.** 캘린더 피드에는 제출 정보가 없어서, 냈으면 직접 체크해야 합니다.
- 알림은 기본으로 꺼져 있습니다. 필요하면 할일을 열어 「알림」을 설정하세요.
- 피드에 무엇이 포함되는지는 Canvas가 정합니다 (학교 설정에 따라 다를 수 있음).

## 문제가 생기면

| 증상 | 원인 / 해결 |
|---|---|
| "캘린더 피드 주소가 아닙니다" | `/feeds/calendars/….ics` 로 끝나는 주소인지 확인. 개발자 도구의 `api/v1/...` 주소는 받지 않습니다 |
| "Canvas가 이 주소를 거부했습니다" | 주소가 잘렸거나 바뀜 — Canvas에서 다시 복사해 **연결 해제 → 다시 연결** |
| "Canvas에 연결하지 못했습니다" | 인터넷 연결 확인. 자동 확인은 30분 뒤 다시 시도합니다 |
| "방금 가져왔습니다 — N초 뒤에…" | 버튼은 1분에 한 번까지 |
| 과제가 안 보임 | 마감일이 없는 과제이거나, 이미 지난 과제 (처음 연결 시 지난 것은 제외) |

## 연결 해제

💾 → Canvas 줄 아래 **연결 해제**. 저장된 피드 주소만 지워지고, 이미 가져온 할일은 그대로 남습니다.
완전히 지우려면 `data/.canvas.json` 파일을 삭제하세요 (이 경우 다시 연결하면 지웠던 과제도 다시 들어옵니다).
