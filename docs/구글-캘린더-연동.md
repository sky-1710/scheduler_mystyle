# Google 캘린더 연동 — 휴대폰으로 알림 받기

PC가 꺼져 있어도 폰에서 일정 알림을 받기 위한 기능입니다.
앱이 일정을 **Google 캘린더로 내보내면**, 폰의 기본 캘린더가 알아서 알림을 띄웁니다.
알림 주체가 PC가 아니라 폰이 되므로 PC 전원과 무관해집니다.

## 동작 방식

- `내 스케줄러`라는 **전용 캘린더를 새로 만들어** 거기에만 씁니다.
  기존 캘린더는 건드리지 않고, 연동을 그만두려면 그 캘린더만 지우면 깔끔하게 정리됩니다.
- 로컬 일정 ↔ 구글 일정의 짝은 `data/.gcal_map.json`에 따로 보관합니다.
  `schedule_data.json`은 전혀 바뀌지 않습니다.
- 일정을 고치면 **4초 뒤 자동으로** 반영됩니다. 여러 건을 연달아 고쳐도 한 번만 동기화합니다.
- 로컬에서 지운 일정은 구글에서도 지워집니다.

### 무엇이 넘어가는가

| 로컬 | Google 캘린더 |
|---|---|
| 시작·종료 시간이 있는 일정 | 시간 지정 일정 |
| 시간 없는 일정 / 할일 | 하루 종일 일정 (제목 앞에 ☑) |
| 기간 일정 (시작~종료) | 여러 날에 걸친 하루 종일 일정 |
| 반복 (매일·N일마다·매주·매월·매년) | 반복 규칙(RRULE)으로 변환, 종료일 포함 |
| 알림 (N분 전) | 팝업 알림 N분 전 |
| 색상 | 가장 가까운 구글 색상 |

**주간·월간 할일은 넘어가지 않습니다.** 특정 날짜가 아니라 그 주·그 달 전체에 걸린 항목이라
캘린더에 놓을 자리가 없습니다.

> **알림을 받으려면 일정에 "알림"이 설정돼 있어야 합니다.** 기본값은 "알림 없음"이라,
> 그대로 두면 캘린더에는 올라가지만 폰이 울리지 않습니다.

## 최초 설정 (약 10분, 한 번만)

Google API 인증은 본인 계정으로 직접 발급해야 합니다.

### 1. Google Cloud 프로젝트 만들기

1. <https://console.cloud.google.com> 접속
2. 상단 프로젝트 선택 → **새 프로젝트** → 이름 아무거나 (예: `my-scheduler`) → 만들기

### 2. Calendar API 켜기

1. 좌측 메뉴 **API 및 서비스 → 라이브러리**
2. `Google Calendar API` 검색 → **사용**

### 3. 동의 화면 설정

1. **API 및 서비스 → OAuth 동의 화면**
2. User Type: **외부** 선택 → 만들기
3. 앱 이름 `내 스케줄러`, 사용자 지원 이메일·개발자 이메일에 본인 주소 입력 → 저장
4. 범위(Scopes)는 건너뛰어도 됩니다
5. **테스트 사용자**에 본인 Google 계정을 추가 → 저장

> 게시 상태를 "테스트"로 두면 토큰이 7일마다 만료됩니다.
> 계속 쓰려면 동의 화면에서 **앱 게시(프로덕션으로 전환)**를 눌러두세요.
> 본인만 쓰는 앱이라 구글 심사는 필요 없습니다.

### 4. OAuth 클라이언트 만들기

1. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
2. 애플리케이션 유형: **데스크톱 앱**
3. 만들기 → **JSON 다운로드**

### 5. 인증 파일 넣기

내려받은 JSON 파일의 이름을 바꿔 아래 경로에 둡니다:

```
C:\Users\Owner\scheduler\data\.gcal_credentials.json
```

> 이 파일과 로그인 후 생기는 `.gcal_token.json`은 **계정 접근 권한 그 자체**입니다.
> `.gitignore`에 등록해 뒀으니 커밋되지 않지만, 다른 곳에 복사하거나 공유하지 마세요.

### 6. 앱에서 연결

1. 앱 재시작
2. 상단 💾 버튼 → **Google 캘린더 연결**
3. 브라우저가 열리면 본인 계정으로 로그인하고 권한 허용
   ("이 앱은 확인되지 않았습니다" 경고가 나오면 **고급 → 이동**)
4. 돌아오면 자동으로 첫 동기화가 실행됩니다

### 7. 폰에서 확인

1. 폰의 Google 캘린더 앱 → 설정
2. **내 스케줄러** 캘린더가 목록에 보이면 **동기화 켜기**
3. 일정 알림이 폰으로 옵니다

## 문제가 생기면

| 증상 | 원인 |
|---|---|
| "설정 필요"에서 안 바뀜 | `.gcal_credentials.json` 경로·이름 확인 |
| 로그인이 7일마다 풀림 | OAuth 동의 화면이 "테스트" 상태 — 앱 게시로 전환 |
| 폰에 캘린더가 안 보임 | 폰 캘린더 앱 설정에서 해당 캘린더 동기화를 켜야 함 |
| 캘린더엔 있는데 알림이 없음 | 일정의 "알림"이 "알림 없음"으로 되어 있음 |
| 중복 일정이 생김 | `data/.gcal_map.json`을 지우고 구글 쪽 `내 스케줄러` 캘린더도 비운 뒤 다시 동기화 |

## 연동 끊기

1. Google 캘린더에서 `내 스케줄러` 캘린더 삭제
2. `data/.gcal_token.json`과 `data/.gcal_map.json` 삭제
3. 필요하면 <https://myaccount.google.com/permissions> 에서 앱 접근 권한 해제
