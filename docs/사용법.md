# 사용법

하단 탭으로 6개 화면을 오갑니다: **📅 월간 · 📆 주간 · ⏱️ 일간 · 🔥 습관 · ✅ 할일 · 📊 통계**

---

## 공통 조작

### 헤더
- **⏺ 기록 칩** — 타이머가 돌고 있으면 어느 탭에서든 헤더에 경과 시간이 깜빡이며 표시됩니다. **클릭하면 즉시 중지** (좁은 화면에서는 점만 표시)
- **📌** — 왼쪽 D-day 패널 열기/닫기 (상태 저장됨)
- **‹ › / 오늘** — 현재 뷰 기준으로 이동 (월간이면 달, 일간이면 하루, 통계는 선택된 기간 단위)
- **🧩** — **위젯 모드**: 다른 프로그램 위에 항상 떠 있는 미니 창을 엽니다 (Chrome/Edge 116+).
  - 데스크톱 앱에서는 제목 표시줄 없는 둥근 카드로 뜹니다 — **빈 곳을 끌어 옮기기**(자리 기억), **—** 로 작은 알약으로 접기, **⤢** 로 펼치기.
  - 타이머 방식 **「기록 / 뽀모도로 / 집중 모드」** 중 하나를 고릅니다.
  - **줄 클릭 = 그 할일/습관의 타이머 시작** ⏺ — 기록 중에는 위젯이 **집중 화면**(스톱워치, 뽀모도로면 남은 시간 링)으로 바뀝니다. 다시 클릭/■ 중지로 종료, 시간은 1분 단위로 적립.
  - **동그라미 클릭 = 완료 체크**, **✕ 두 번 클릭 = 삭제** (가져온 할일은 오늘 목록에서만 제거)
  - **입력창에 제목 입력 후 Enter = 오늘 할일 바로 추가** (같은 제목이 있으면 색·카테고리 자동 상속)
  - **불러오기** = 다른 날짜의 미완료 할일·월간/주간 할일을 오늘로 가져오기 (일간 탭 「가져오기」와 같음). 입력창에 치면 후보 검색
  - 본체 창과 실시간 동기화. (본체 탭이 닫히면 위젯도 닫힘)
- **🔍** — 통합 검색 (할일·일정·습관·메모·목표·반성)
- **🌙/☀️** — 다크 모드 전환
- **+** — 일정/할일 추가

### 키보드 단축키
| 키 | 동작 |
|---|---|
| `1`~`6` | 월간 / 주간 / 일간 / 습관 / 할일 / 통계 탭 전환 |
| `N` | 새 일정/할일 추가 |
| `T` | 오늘로 이동 |
| `/` | 검색 열기 |
| `←` `→` | 이전/다음 (기간 이동) |

### 일정/할일 만들기 (+ 버튼)
- **유형 토글**: "일정"(날짜·시간 지정) ↔ "할 일"(체크리스트). 할 일이면 **완료 여부** 토글도 나타나며, 수정 중 토글하면 즉시 반영됩니다.
- **기간 (시작일~종료일)**: 종료일을 넣으면 기간 일정이 됩니다 (시험기간, 프로젝트 등). **월간 달력에서는 날짜를 가로지르는 연속 막대**로 표시되고(겹치면 최대 3줄로 쌓임, 막대 클릭 = 수정), 주간·일간에는 기간 내 매일 나타납니다. **D-day는 종료일 기준**으로 계산되며 패널에 `7월 6일 ~ 7월 9일` 범위로 표시됩니다. 반복과는 함께 쓸 수 없어요 (반복 선택 시 종료일 필드 숨김)
- **할일 범위**: 특정 날짜(기본) / **주간 할일**(그 주 전체 목표) / **월간 할일**(그 달 전체 목표). 주간·월간을 고르면 시간·반복 필드는 숨겨지고, 날짜는 "어느 주/달 소속인지"를 정하는 기준이 됩니다
- **반복**: 매일 / **N일마다(직접 입력)** / 매주 / 매월 / 매년 + 반복 종료일
  - 반복 할일의 완료 체크는 **날짜별로 따로** 기록됩니다 (오늘 체크해도 내일은 미완료로 시작)
- **알림**: 5분 전 ~ 하루 전 (앱이 열려 있을 때 울림)
- **카테고리**: 드롭다운에서 선택, **⚙ 관리**로 생성/수정. 제목이 기존 할일과 같으면 카테고리가 자동 지정됩니다.
- **색상 / 중요도 / 정확도(%) / 메모**

## 📅 월간

- 날짜 칸에 일정 칩이 표시되고, 날짜 숫자 옆에 그날의 **습관 %(주황)** 와 **할일 %(보라)** 가 보입니다.
- 날짜 클릭 → 상세 모달: 일정 목록 / **⏱️ 10분 타임블록 보기** / **📆 이 주의 주간 보기** / 일정 추가
- **왼쪽 패널 하단 "🗓 N월 할일"**: 이 달의 월간 할일 목록. 동그라미 = 완료 체크, 줄 클릭 = 수정, ＋ = 바로 추가. 지난달 미완료가 있으면 **"↪ 이월하기" 버튼**이 나타납니다. (주간 탭에서는 "📆 이번 주 할일"이 같은 자리에 표시)
- 월간/주간 할일은 달력 날짜 칸·D-day·일별 %에는 나타나지 않고, 일간 뷰의 📥 가져오기로 특정 날에 끌어와 작업할 수 있습니다.

## 📆 주간

- 상단: 요일별 **습관 체크리스트 카드** — 달성률 %와 진행바(주황=습관, 보라=할일), 체크박스 클릭으로 그 날짜에 체크
- 하단: 시간표 그리드 — 빈 칸 클릭으로 그 시간에 일정 추가, 일정 클릭으로 수정

## ⏱️ 일간 (DAILY PLANNER)

종이 플래너 스타일의 하루 페이지입니다.

### 상단 박스
- **DATE.** 날짜 / **GOAL.** 오늘의 목표(날짜별 저장)
- **DONE.** `할일 50% (1/2) · 습관 60% (3/5)` + **최근 7일 스파크라인** (빨간 막대 = 보는 날짜)
- **WAKE. / SLEEP.** 일어난 시간·잠자리에 든 시간 기록. 어제 취침~오늘 기상으로 **😴 수면 시간이 자동 계산**되어 WAKE 옆에 표시됩니다 (자정 넘김 처리됨). 기록하면 TIME PLAN 그리드의 해당 시각에 **빨간 세로선**(☀️ 기상 / 🌙 취침)이 그어집니다

### TO DO LIST
- **＋ 추가** — 이 날짜의 할일 바로 만들기
- **📥 가져오기** — 등록된 전체 할일 중 골라서 이 날로 가져오기
- **🧹 지우개** — 색칠 지우기 모드
- 할일이 **카테고리별 그룹**으로 표시됩니다. 동그라미 클릭 = 완료 체크, **줄 클릭 = 🖌️ 색칠 대상으로 선택**, ✎ = 수정
- 칠한 시간 합계(`30분`)가 각 줄에 표시됩니다

### HABIT TRACKER
습관도 동일하게 동작합니다 — 동그라미로 체크, 줄 클릭으로 색칠 대상 선택.

### TIME PLAN (10분 타임블록)
- 밤 12시(자정)부터 다음 날 밤 12시까지 24시간 × 6칸(10분) 그리드
- 할일/습관을 선택한 뒤 **클릭 또는 드래그로 색칠** → 그 색으로 채워지고 이름이 표시됩니다
- **1분 단위 색칠**: 칸 안에서 누른 위치만큼 채워집니다 (칸의 30% 지점 클릭 = 3분). 드래그로 지나간 칸은 꽉 채워지고, 마지막 칸은 놓은 위치만큼 부분 채움
- **한 칸에 여러 작업**: 10:00~10:05 공부, 10:05~10:10 운동처럼 칸 하나를 나눠 칠할 수 있습니다. 다른 작업으로 칠하면 겹친 분만 바뀌고 나머지는 그대로 남습니다 (타이머로 칸 중간에 작업을 바꿔도 마찬가지)
- 자기 색 위를 다시 누르면 그 작업만 지워집니다 (같은 칸의 다른 작업은 남음)
- 🧹 지우개는 누른 위치의 작업만 지웁니다. 칸의 빈 곳을 누르면 칸 전체를 지웁니다
- **타이머 (열품타 방식)** — TO DO LIST/HABIT 줄을 클릭하면 즉시 스톱워치가 시작되고 상단에 초 단위 타이머 바가 표시됩니다. 시간은 **1분 단위로 정확하게 적립**되고(수동 색칠은 블록당 10분), 현재 10분 블록도 자동으로 칠해집니다. 같은 줄 재클릭 = 중지, 다른 줄 클릭 = 전환. ▶ 지금 기록 버튼으로도 시작 가능.
- 제목 옆에 `총 4시간 30분 기록` 합계 표시

### MEMO
- 모눈종이 메모장 (날짜별 저장, 입력하면 자동 저장)
- **🖼️ 사진 추가** 버튼 또는 **Ctrl+V 붙여넣기**로 사진 첨부 → 썸네일 클릭 = 크게 보기, ✕ = 삭제

### TODAY'S REVIEW (하루 평가) — TIME PLAN 아래 오른쪽 열
- **⭐ 별점**: 별 10개 중 클릭한 만큼이 오늘 점수 (같은 별 재클릭 = 취소). 통계의 별점 추이 그래프에 반영
- **반성 칸**: 오늘 한 나쁜 습관·아쉬웠던 일 기록 (날짜별 자동 저장, 🔍 검색 대상에 포함)

## 🔥 습관

- 한 달 그리드: 세로 = 습관, 가로 = 날짜. 칸 클릭으로 체크.
- 습관 이름 옆에 `12/31 · 39%` 달성률 표시, 이름 클릭 = 수정/삭제
- **＋ 습관 추가**: 이름, 카테고리, 색상 지정

## ✅ 할일

기한 초과 / 오늘 / 예정 / 날짜 없음 / **완료(접힘)** / **🗄 보관됨(접힘)** 섹션으로 정리됩니다.
- 우선순위(🔴높음 → 🟡보통 → 🟢낮음) 순 정렬
- 완료 후 14일이 지난 일반 할일은 자동으로 보관됨 섹션으로 이동합니다

## 📊 통계

상단 **[주간 | 월간 | 연간]** 토글로 기간을 바꿉니다. ‹ › 는 선택된 기간 단위로 이동.
**⬇ CSV** 버튼으로 현재 기간의 시간 기록(날짜·이름·유형·카테고리·분)을 Excel용 CSV로 내보낼 수 있습니다.

### 주간
구성 순서: 요약 카드 → 📉 추이 그래프 → 🎯 목표 → 막대 그래프 → 카테고리 분석 (월간도 동일)
- 요약 카드: 기록 시간 / 할일 완료율 / 습관 달성률 — **지난주 대비 ▲▼ 증감**
- **📉 추이 그래프**: 기록 시간·하루 별점 라인 차트 (월간은 일별, 연간은 월별 집계. 별점 없는 날은 선이 끊겨 표시)
- **🎯 주간 목표**: 카테고리에 목표 시간을 설정했다면 진척 바 표시 (달성 시 🎉)
- **요일별 기록 시간** 스택 막대 → 무너지는 요일 파악
- 카테고리별 시간·성공률, 습관 달성률

### 월간
- 지난달 대비 증감 / **일별 기록 시간** 그래프 + 주차별 소계
- 카테고리별 기록 시간(중첩 롤업) / 성공률 / 습관 스트릭

### 연간
- **🌱 잔디 히트맵**: 365일, 기록 시간이 많을수록 진하게
- 월별 기록 시간 12개 막대 / 최장 습관 스트릭 / 카테고리별 연간 시간

## 📁 카테고리

일정/습관 모달의 **⚙ 관리**에서:
- 이름 + 색 + **상위 카테고리** 지정으로 중첩 (`공부 > 수학`)
- **주간 목표 시간** 입력 시 주간 통계에 진척 바 표시
- 삭제하면 하위 카테고리·할일은 상위로 자동 이동
- 통계의 시간·성공률은 하위 → 상위로 합산(롤업)됩니다

## 💾 백업

| 버튼 | 동작 |
|---|---|
| 📁 data 폴더 연결 | 모든 변경을 `schedule_data.json`에 자동 저장 + 주 1회 스냅샷(사진 제외, 최근 8개 유지) |
| ⬇ 다운로드 | 전체 데이터(사진 포함)를 JSON 한 파일로 저장 |
| ⬆ 가져오기 | JSON 파일로 현재 데이터를 통째로 교체. 폴더 연결 시 **교체 직전 상태를 `schedule_before_import_…json`으로 자동 백업** |
