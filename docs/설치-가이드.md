# 설치 가이드

이 앱은 **자체 창으로 실행되는 데스크톱 앱**입니다. 브라우저는 필요 없습니다.
화면과 기능은 전부 `index.html` 하나에 들어 있고, 파이썬 셸이 그 화면을 자기 창에 띄우면서
파일 저장과 Windows 알림을 맡습니다.

## 폴더 구성

```
scheduler/
├── index.html            ← 앱 화면과 기능 전부 (이 파일이 본체)
├── run.pyw               ← 실행 진입점
├── app/                  ← 데스크톱 셸
│   ├── main.py             창 + 트레이 상주
│   ├── bridge.py           화면 ↔ 파이썬 연결 (저장·알림)
│   ├── storage.py          schedule_data.json 읽기·쓰기, 스냅샷
│   ├── toast.py            Windows 네이티브 알림
│   └── shortcuts.py        바로가기 + AppUserModelID 등록
├── assets/               ← 시작 화면 배경 이미지
├── data/                 ← 자동 저장 폴더
│   ├── schedule_data.json          ← 메인 데이터 (자동 저장)
│   └── schedule_backup_YYYY-MM-DD.json  ← 주간 스냅샷 (최근 8개 자동 유지)
├── .venv/                ← 파이썬 환경 (git 제외)
├── docs/                 ← 문서
└── tests/                ← 자동 테스트 (개발용, tests/README.md 참고)
```

## Windows에서 사용하기

### 실행
바탕화면의 **내 스케줄러** 아이콘을 누릅니다. 자체 창으로 열립니다.
PySide6에 Chromium이 포함돼 있어 Chrome·Edge 설치 여부와 무관하게 동작합니다.

### 저장
`data/schedule_data.json`에 **자동 저장**됩니다. 연결이나 권한 허용 절차가 없습니다.
쓰기는 임시 파일에 먼저 기록한 뒤 교체하는 방식이라, 저장 도중 앱이 꺼져도
파일이 깨진 채로 남지 않습니다.

7일마다 `schedule_backup_YYYY-MM-DD.json` 스냅샷이 생기고 최근 8개가 유지됩니다.

### 알림
일정에 **시작 시간**과 **알림**을 설정하면 그 시각에 Windows 알림이 뜹니다.
알림 방식은 두 가지 중 고를 수 있습니다:

| 방식 | 동작 |
|---|---|
| 일반 | 잠시 떴다가 알림 센터로 들어갑니다 |
| 알람 | 직접 닫을 때까지 화면에 남고, 5·10·30분 뒤 다시 알림을 고를 수 있습니다 |

마지막으로 고른 방식이 다음 일정의 기본값이 됩니다.
할일(투두)과 주간·월간 할일에는 시간이 없으므로 알림도 걸리지 않습니다.

> 창을 닫아도 앱은 **트레이에 남아** 계속 실행되므로 알림이 그대로 동작합니다.
> 완전히 끄려면 트레이 아이콘 우클릭 → 종료. (끄면 알림도 멈춥니다.)

### 위젯 · 뽀모도로
상단 위젯 버튼을 누르면 **항상 위에 떠 있는 작은 카드**가 열립니다 (빈 곳을 끌어서 옮기고, — 로 접기).
타이머 방식에서 「뽀모도로」를 고르면 설정이 나옵니다. **집중 시간과 휴식 시간을 따로** 정합니다 —
각 줄의 `−`/`+` 로 5분 단위 조절 (집중 5~120분, 휴식 0~60분).

위젯에서는 **모드를 고르기만** 합니다. 「뽀모도로」를 골라두면 평소처럼 지내다가,
**할 일을 누르는 순간 그 할 일로 집중이 시작**됩니다. 따로 「시작」을 누를 필요가 없습니다.

| 구간 | 끝나면 |
|---|---|
| 집중 | 알림 한 번 → **할 일 기록을 멈추고** 「휴식 시작」 버튼이 나타남 (자동 전환 아님) |
| 휴식 | 알림 한 번 → **같은 할 일로 집중을 다시 시작** |

**중지할 때까지 계속 돕니다.** 집중 → (버튼) → 휴식 → 집중 → … 반복이고,
「중지」나 할 일을 다시 눌러 기록을 멈추면 끝납니다.

휴식으로 넘어갈 때 기록을 멈추는 건 **쉬는 시간이 공부 시간으로 잡히지 않게** 하기 위해서입니다.
휴식을 **0분(없음)** 으로 두면 집중만 하고 끝납니다.
「기록」을 고르면 평소대로 시간 기록만 됩니다.

**집중 모드** — 타이머 방식에서 「집중 모드」를 고르면, 할 일을 한 번만 눌러도
집중 → 휴식 → 같은 할 일로 집중 → … 이 **버튼 없이** 「중지」할 때까지 계속 이어집니다.
휴식이 0분이면 집중만 연달아 돕니다. 자세한 흐름은 [README-사용-가이드.md](../README-사용-가이드.md#8-집중-모드-연속-뽀모도로).

> **알림 소리가 나올 장치를 직접 고를 수 있습니다.**
> 위젯에서 「뽀모도로」를 고르면 집중·휴식 아래에 나오는 「소리」에서 스피커·이어폰 등 원하는 장치를 고르고
> ▶ 로 미리 들어보세요. 이어폰을 꽂거나 빼면 목록이 바로 바뀝니다.
> 기본값은 Windows 기본 출력 장치이고, 고른 장치가 빠져 있으면 그동안은 기본 장치로
> 울립니다 (다시 연결하면 고른 장치로 돌아갑니다).
> 소리 파일은 `assets/alarm.wav` 로 첫 실행 때 자동 생성됩니다 (지워도 다시 만들어집니다).

카운트다운은 앱 본체에서 돌기 때문에 **위젯을 닫아도 세션은 계속 진행되고 끝나면 알림이 옵니다.**
남은 시간은 시간 기록 중(집중 화면)에도 같이 보입니다.

### 시작 프로그램 등록
PC를 켜면 자동으로 뜨게 하려면:

```powershell
.venv\Scripts\python run.pyw --autostart on
```

끄려면 `--autostart off`. 시작 폴더의 바로가기 하나를 넣고 빼는 방식이라
`shell:startup` 을 열어 직접 지워도 됩니다.

### 시작 화면 (Vision)
앱을 그날 처음 열면 목표를 상기시키는 전체 화면이 한 번 뜹니다.
할 일이나 통계는 없고, **더 잘해야지 / 목표 경로 / 되고 싶은 연구자** 세 가지만 담았습니다.
「들어가기」나 Esc 로 닫히고, 하루에 한 번만 나타납니다.
「이 화면 그만 보기」로 끄고 💾 메뉴에서 다시 켤 수 있습니다.

배경 사진은 `assets/start-hero.jpg` 입니다. 바꾸려면 같은 경로에 다른 이미지를 넣으면 되고,
가로로 긴 사진일수록 잘 맞습니다. (`assets/start-hero-source.png` 는 원본 레퍼런스)

### 처음 설치할 때 (개발자용)

```powershell
cd C:\Users\Owner\scheduler
py -m venv .venv
.venv\Scripts\python -m pip install PySide6-Essentials PySide6-Addons winsdk pywin32
.venv\Scripts\python run.pyw --install
```

`--install`은 바탕화면과 시작 메뉴에 바로가기를 만듭니다.
시작 메뉴 바로가기에는 AppUserModelID(`Scheduler.App`)가 박혀 있는데,
**Windows는 이 등록이 없는 일반 데스크톱 앱의 알림을 오류 없이 무시합니다.**
알림이 안 뜨면 이 단계를 건너뛰지 않았는지 먼저 확인하세요.

바로가기를 지우려면 `.venv\Scripts\python run.pyw --uninstall`.

## Android에서 사용하기

데스크톱 셸은 Windows 전용이지만, `index.html`은 그대로 브라우저에서도 열립니다.

### 방법 1 — 파일 직접 복사 (간단)
1. `index.html`을 폰으로 복사 (USB, 카카오톡 나에게 보내기, 클라우드 등)
2. 파일 관리자에서 Chrome으로 열기
3. Chrome 메뉴(⋮) → **홈 화면에 추가** → 앱 아이콘처럼 사용

> 이 방식은 브라우저 저장소만 쓰므로, 백업은 **⬇ 다운로드** 버튼을 이용하세요.

### 방법 2 — 같은 Wi-Fi에서 PC 서버로 열기
```powershell
cd C:\Users\Owner\scheduler
python -m http.server 8000
```
폰 Chrome에서 `http://PC의IP주소:8000` 접속 → 홈 화면에 추가.

### 기기 간 데이터 이동
1. PC 앱에서 **⬇ 다운로드** → `schedule_data.json` 저장
2. 파일을 기기 B로 전송
3. 기기 B에서 **⬆ 가져오기** → 파일 선택 (현재 데이터를 파일 내용으로 교체)

사진, 습관, 카테고리, 타임블록까지 **모든 데이터가 한 파일**에 들어 있습니다.

## 데이터 저장 위치

| 데이터 | 저장 위치 |
|---|---|
| 일정·할일·습관·카테고리 등 | `data/schedule_data.json` (자동) |
| 메모 사진 | `schedule_data.json` 안에 함께 저장 |
| 백업 스냅샷 | `data/schedule_backup_날짜.json` (사진 제외, 최근 8개) |

데스크톱 앱은 파일에 바로 쓰기 때문에, 브라우저 데이터를 지워도 기록이 사라지지 않습니다.
(브라우저로 열어 쓰는 경우에는 여전히 ⬇ 다운로드 백업이 필요합니다.)

## 데이터 복구

실수로 데이터를 잃었을 때, `data/` 폴더의 복구 소스 (최신순 선택):
1. `schedule_data.json` — 메인 데이터 (사진 포함)
2. `schedule_before_import_날짜_시각.json` — 가져오기 직전 자동 백업 (사진 포함)
3. `schedule_backup_날짜.json` — 주간 스냅샷 (사진 제외, 최근 8개)

앱에서 **⬆ 가져오기** → 해당 파일을 선택하면 됩니다.
