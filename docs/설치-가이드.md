# 설치 가이드

이 앱은 **단일 HTML 파일**이라 별도의 설치 프로그램이 없습니다. 파일을 열기만 하면 됩니다.

## 폴더 구성

```
scheduler/
├── index.html            ← 앱 본체 (이 파일 하나로 동작)
├── data/                 ← 자동 저장 폴더 (폴더 연결 시 사용)
│   ├── schedule_data.json          ← 메인 데이터 (자동 저장)
│   └── schedule_backup_YYYY-MM-DD.json  ← 주간 스냅샷 (최근 8개 자동 유지)
├── README.md
├── docs/                 ← 문서
└── tests/                ← 자동 테스트 (개발용, tests/README.md 참고)
```

## Windows에서 사용하기

### 기본 실행
`index.html`을 더블클릭하거나 Chrome/Edge로 엽니다.

### 앱처럼 실행 (권장)
주소창 없는 독립 창으로 쓰고 싶다면 바로가기를 만듭니다:

1. 바탕화면 우클릭 → 새로 만들기 → 바로 가기
2. 위치에 입력 (경로는 본인 환경에 맞게):
   ```
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --app="file:///C:/Users/Owner/scheduler/index.html"
   ```
3. 이름을 "내 스케줄러"로 저장 → 더블클릭하면 앱 창으로 열립니다.

### 데이터 폴더 연결 (자동 저장, 최초 1회)
1. 앱 상단의 **📁 data 폴더 연결** 버튼 클릭
2. `scheduler/data` 폴더 선택 → 권한 허용
3. 버튼이 **✅ 자동저장 중** 으로 바뀌면 완료. 이후 모든 변경이 `schedule_data.json`에 즉시 저장되고, 7일마다 스냅샷 백업이 자동 생성됩니다.

> 브라우저를 완전히 껐다 켜면 권한 확인 창이 다시 뜰 수 있습니다. 허용하면 저장된 연결이 복원됩니다.

### 알림 사용
첫 실행 시 브라우저가 알림 권한을 물어봅니다. **허용**해야 일정 알림(N분 전)이 동작합니다.
알림은 **앱이 열려 있는 동안** 울립니다. 자정이 지나면 다음 날 알림이 자동으로 다시 예약됩니다.

## Android에서 사용하기

### 방법 1 — 파일 직접 복사 (간단)
1. `index.html`을 폰으로 복사 (USB, 카카오톡 나에게 보내기, 클라우드 등)
2. 파일 관리자에서 Chrome으로 열기
3. Chrome 메뉴(⋮) → **홈 화면에 추가** → 앱 아이콘처럼 사용

> 이 방식은 자동 저장 폴더 연결이 안 되므로, 데이터 백업은 **⬇ 다운로드** 버튼을 이용하세요.

### 방법 2 — 같은 Wi-Fi에서 PC 서버로 열기
PC에 Python이 있다면:
```powershell
cd C:\Users\Owner\scheduler
python -m http.server 8000
```
폰 Chrome에서 `http://PC의IP주소:8000` 접속 → 홈 화면에 추가.

### 기기 간 데이터 이동
1. 기기 A에서 **⬇ 다운로드** → `schedule_data.json` 저장
2. 파일을 기기 B로 전송
3. 기기 B에서 **⬆ 가져오기** → 파일 선택 (현재 데이터를 파일 내용으로 교체)

사진, 습관, 카테고리, 타임블록까지 **모든 데이터가 한 파일**에 들어 있습니다.

## 데이터 저장 위치

| 데이터 | 저장 위치 |
|---|---|
| 일정·할일·습관·카테고리 등 | 브라우저 localStorage + `data/schedule_data.json` (연결 시) |
| 메모 사진 | 브라우저 IndexedDB (용량 큼) + `schedule_data.json` |
| 백업 스냅샷 | `data/schedule_backup_날짜.json` (사진 제외, 최근 8개) |

> ⚠️ **폴더를 연결하지 않고 브라우저 데이터(캐시/사이트 데이터)를 삭제하면 기록이 사라집니다.**
> 반드시 폴더 연결을 해두거나 주기적으로 ⬇ 다운로드 백업을 해주세요.

## 데이터 복구

실수로 데이터를 잃었을 때, `data/` 폴더의 복구 소스 (최신순 선택):
1. `schedule_data.json` — 메인 데이터 (사진 포함)
2. `schedule_before_import_날짜_시각.json` — 가져오기 직전 자동 백업 (사진 포함)
3. `schedule_backup_날짜.json` — 주간 스냅샷 (사진 제외, 최근 8개)

앱에서 **⬆ 가져오기** → 해당 파일을 선택하면 됩니다.

> 💡 앱을 **여러 창/탭에 동시에 열어도** 됩니다 — 한쪽에서 저장하면 다른 쪽이 자동으로 최신 상태로 갱신됩니다.
